# Tech Lab

モダンなWeb開発技術を中心に、技術検証やサンプルプロジェクトを公開するリポジトリです。

## Purpose

実務経験を踏まえながら、新しい技術や開発手法を実際に試し、その特徴や活用方法を検証します。

## Areas of Interest

* Backend Development
* Frontend Development
* Database Design
* Infrastructure and DevOps
* Software Architecture

## Policy

* 実際に動作を確認したコードを公開する
* 技術的な仕様や公式ドキュメントを確認する
* 個人情報や機密情報を含めない
* 検証内容や学んだことを技術記事として発信する

## Blog

技術検証の内容や開発・運用で得た知見を、noteで発信しています。
